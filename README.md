
# Customer Risk & Churn Analytics Dashboard

## 📊 Project Overview

Customer Risk & Churn Analytics Dashboard is a machine learning and business analytics project designed to identify customers who are at risk of churn.

The project uses customer data, machine learning predictions, risk probability analysis, and an interactive Streamlit dashboard to help understand customer risk.

## 🎯 Objectives

- Analyze customer data
- Predict customer churn/risk
- Calculate risk probability
- Categorize customers into Low, Medium, and High Risk
- Identify high-risk customers
- Visualize customer risk using an interactive dashboard

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Plotly
- Streamlit
- Google Colab
- Git & GitHub

## 🤖 Machine Learning

The project uses Logistic Regression for customer risk prediction.

The model was evaluated using:

- Accuracy
- Precision
- Recall
- Classification Report
- Confusion Matrix

## 📈 Dashboard Features

- Total customer KPI
- High-risk customer count
- Medium-risk customer count
- Low-risk customer count
- Risk category distribution
- Risk probability distribution
- High-risk customer table
- Interactive risk filtering
